# サンプル: 実機から受信した TOKUDER の TCH 音声フレーム

**ここにあるフレームは、実機の無線機から送信した電波を受信してキャプチャした、そのままのデータです。**
シミュレーションでも、エンコーダーで作ったものでもありません。誤り訂正もかけておらず、受信機が出したビットと LLR を手を加えずに保存しています。

- **入っているのは TCH（音声）フレームだけ**です。制御チャネル（PICH・SACCH など）は含みません。
- **受信の状態**: どのサンプルにも消失フレームはありません。また、全フレームに受信機自身の LLR が付いています（値を補ったフレームはありません）。

## ファイル

| ファイル | 内容 |
|---|---|
| `<名前>.bin` | 受信したフレームの硬判定ビット。1 フレーム 9 バイト（72 bit、送信順、MSB 先頭）、20 ms ごと。先頭は 80 ms の RF フレームの第 0 スロット |
| `<名前>.llr` | 受信機が出した軟判定値（int8、1 フレーム 72 個、正 = 1） |
| `samples.json` | 各サンプルの話者・性別・テキスト・元の発話 ID |

| 名前 | 話者 | 長さ |
|---|---|---|
| `vctk_p301_female` | VCTK p301（女性） | 9.20 秒 |
| `vctk_p351_female` | VCTK p351（女性） | 9.52 秒 |
| `vctk_p316_male` | VCTK p316（男性） | 9.04 秒 |
| `vctk_p258_male` | VCTK p258（男性） | 9.12 秒 |

- **未知の話者です**: 4 人とも、同梱モデルの学習には使っていない話者です（評価用のテスト話者）。
- **送信した音声**: VCTK の発話を 0.1 秒の間隔でつないだものです。元の発話 ID は `samples.json` の `components` にあります。

## 復号

```bash
tokuder2wav samples/vctk_p301_female.bin out.wav --llr samples/vctk_p301_female.llr
```
